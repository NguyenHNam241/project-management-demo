# Project Management Demo

Dự án thực hành **Setup tài khoản GitHub và tạo Repository / Project**.

## Mô tả dự án

Repository này dùng để luyện tập quy trình làm việc trên GitHub:

- Tạo repository và khởi tạo `README.md`
- Thực hành commit, tạo branch và merge qua Pull Request
- Quản lý công việc bằng **GitHub Projects** (mẫu Kanban)
- Tạo Issue và phân loại theo trạng thái: Backlog → Ready → In progress → In review → Done

## Danh sách công việc (Issues)

| # | Công việc | Trạng thái |
|---|-----------|------------|
| 1 | Thiết kế giao diện trang chủ | Done |
| 2 | Xây dựng chức năng đăng nhập | In progress |
| 3 | Viết tài liệu hướng dẫn sử dụng | Ready |
| 4 | Kiểm thử và sửa lỗi | Backlog |
